## Cómo trabajamos (revisión cruzada)

1. Cada tarea se hace en una rama propia, por ejemplo `valery/tarea-1-fuentes` o `maykel/tarea-2-fuentes`.
2. Se abre un Pull Request hacia `main` y se asigna como revisor a la otra persona.
3. La persona que revisa deja comentarios en el PR y lo aprueba. Así queda constancia de que ambos conocen todo el informe (regla 1).
4. Cuando está aprobado, se hace merge a `main`.

Responsables y fechas: ver el documento «Reparto de responsabilidades · Tema 2 ISW-622».
